# Dotfiles

Managed with [chezmoi](https://www.chezmoi.io/). Supports macOS and Arch Linux.

## Quick Start

```sh
chezmoi init https://github.com/<user>/dotfiles.git
chezmoi diff
chezmoi apply
```

## Prerequisites

### macOS

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
source ~/.zprofile

brew install chezmoi neovim ripgrep node tmux zellij font-meslo-lg-nerd-font
brew install --cask ghostty
curl --proto '=https' --tlsv1.2 -LsSf https://setup.atuin.sh | sh

# ccmux — drives the Claude Code status pills (see "Claude Code status pills")
brew install epilande/tap/ccmux
ccmux setup
```

### Arch Linux

```sh
pacman -S chezmoi neovim ripgrep nodejs tmux zellij ttf-meslo-nerd ghostty atuin
```

ccmux is not packaged for Arch — install it from source (needs [Bun](https://bun.sh))
per <https://github.com/epilande/ccmux>, then run `ccmux setup`. See
"Claude Code status pills" below for why it's needed.

### TPM (tmux plugin manager)

```sh
git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm
```

After first tmux launch, press `Ctrl+s I` to install plugins.

## Claude Code status pills (requires ccmux)

Each Claude Code session's state is surfaced as a colored "pill" in its tmux
window tab, so you can see at a glance which agent needs you. The tabs show a
single **worst-of** pill per window (red error → orange permission → blue
question/plan → grey working → dim idle), computed across every session in that
window so one idle session can't mask another's alert.

**This integration depends on [ccmux](https://github.com/epilande/ccmux).** ccmux
runs a daemon that tracks each session's true state (keyed by session UUID, bound
to panes by TTY) and reconciles Esc-dismissed prompts. The renderer reads that
truth rather than guessing from Claude hooks alone — which is what fixes stuck
prompts and multi-session windows. Pieces:

- `dot_config/tmux/tmux.conf.tmpl` — polls the renderer every 2s
  (`status-interval 2` + a `#()` segment appended to `status-right`).
- `dot_claude/hooks/tmux-pills-render.sh` — reads ccmux state
  (`http://127.0.0.1:${CCMUX_PORT:-2269}/sessions`, falling back to
  `ccmux show --json`) and paints one pill per window.
- `dot_claude/hooks/tmux-pills-hook.sh` — Claude Code hook entry that pokes the
  renderer for low latency and tracks the red error overlay.
- `dot_claude/settings.json.tmpl` — wires the hooks (also snapshots ccmux's own
  `ccmux-*` hook entries).

**Setup on a new machine:** install ccmux (above) and run **`ccmux setup`** — it
generates the `ccmux-*.sh` hook scripts that `settings.json` references. Without
ccmux installed and set up, the pill renderer no-ops (it leaves tabs untouched)
and those ccmux hook commands will error. Requires tmux and git 2.31+.

## Usage

```sh
chezmoi edit ~/.config/tmux/tmux.conf   # edit source, apply on save
chezmoi apply                            # apply all changes
chezmoi update                           # pull remote + apply (secondary machine)
```

## Structure

```
dot_config/          → ~/.config/
  atuin/             static
  ghostty/           config.tmpl (macOS titlebar conditional)
  nvim/              static
  tmux/              tmux.conf.tmpl (clipboard: pbcopy vs wl-copy; status pills)
  zellij/            static
dot_claude/          → ~/.claude/  (Claude Code)
  settings.json.tmpl hooks (homeDir-templated); includes ccmux + pill hooks
  hooks/             status-pill scripts: tmux-pills-render.sh, tmux-pills-hook.sh,
                     tmux-state.sh (legacy). ccmux-*.sh are generated by `ccmux setup`.
```
